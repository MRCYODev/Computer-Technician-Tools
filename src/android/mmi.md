# MMI Codes

## What is an MMI Code.
MMI code is a combination of **numbers**, **asterisks**, and **hash symbols** that you enter in your phone's dial pad to perform specific functions or access hidden features. This code is also known as the Man-Machine Interface code and is built into all phones. It helps users communicate directly with the device or mobile network.
